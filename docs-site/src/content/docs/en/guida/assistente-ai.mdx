The **data assistant** answers questions about the selected site's data. It reads records and writes nothing: changes stay in the modules, where you confirm them. It respects module access: it does not read modules excluded from your access to the site.

## Where it is

After you sign in, the **AI** button appears only if the assistant is on for the selected site. Below **1180 px**, it appears in the **top bar**, just before the settings gear. At **1180 px** and above, it appears at the bottom right. The button opens the **Data assistant** panel.

The assistant is off by default, including on existing sites. All site members can see whether it is on in **Settings**, and the site **Owner** can change the setting. See [Assistant settings](../impostazioni/#assistant).

The panel contains:

- the conversation;
- suggestions for the current view;
- the **Ask about this site's data** field and the **Send** button.

On the sign-in screen the buttons are not there.

## Asking a question

What it is for: getting a figure or a list without walking through the views.

1. Open the view you are interested in, so the suggestions are already in the right context.
2. Press **AI** to open the panel.
3. Pick a suggestion or type your question in the **Ask about this site's data** field.
4. Press **Send** and read the answer: cited records appear in square brackets.
5. Open a citation when it is a button: it takes you to the record detail.

Select **×** to close the panel and return focus to the **AI** button.

## The suggestions

Suggestions change with the open view. Some examples:

- in Overview: "What is late on this site?";
- in Tasks: "How many tasks are waiting for verification?";
- in Deviations: "Which deviations are still open?";
- in Site progress: "Which items are behind plan?";
- in Time bookings: "How many hours have been booked in total?";
- in Cost impacts: "How much has been claimed and settled?";
- in Diary: "What was recorded in the diary yesterday?".

You can also type your own question.

## The answers

Answers are short and cite the records used, with the code in square brackets: `[DEV-014]`, `[WBS 2.1]`.

Citations are buttons: they open the record detail when that record type has a detail in the interface. For tasks, diary and work structure the reference stays a label.

## The language

The assistant answers in the interface language:

- Italian interface: it answers in Italian;
- English interface: it answers in English.

Record codes stay the same.

## What it sees

- Only the **selected site**.
- Only data permitted by your site role and module access.
- Records from deviations, site progress, cost impacts, tasks, diary and project structure.
- **Time bookings** access allows totals for app bookings. Individual booking records also require **Worker names and individual hours**.

It does not see other sites and does not read the content of photos and PDFs.

## What it does not do

- **It does not write**: it does not create, edit or close records. If you ask for a change, it points to the screen to use.
- **It does not invent**: if a piece of data is missing, it says it is not in the data.
- **It does not compute totals it did not query**: the numbers in the answers come from queries on the data.

:::caution[If the assistant does not answer]
- If the **AI** button is missing, check the selected site and its status in the **Assistant** section of **Settings**.
- If the request times out, the panel shows a message. Try again, perhaps with a narrower question.
- If you see a message about too many requests, wait before trying again. If the service is unavailable, check your connection and report the problem to whoever administers the installation if it persists.
- If the answer says the data is missing, check the selected site and the view you opened the panel from.
:::

## Practical limits

- A connection is required: questions go through the server.
- The conversation stays in memory for the selected site. Switching sites or reloading the page starts it afresh.
- In the demo, the first time you open a site where the assistant is on, a message says that the data is synthetic.
- Questions and the returned records are sent to the model provider configured on the server. Do not enter confidential information.

For the endpoint list see [REST API](../../riferimento/api/).
