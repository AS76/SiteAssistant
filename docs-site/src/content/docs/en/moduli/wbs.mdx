The **Project structure** view shows the work hierarchy (*Work Breakdown Structure*, WBS) imported from the site's Time Schedule. It is a **read-only** view: it helps you find your way around the work structure, not edit it.

## What you see

The structure is a tree of items identified by a **WBS code** (for example `1`, `1.1`, `1.1.2`). For each item you can see:

- the code and description;
- the level in the hierarchy;
- the imported progress;
- the planned start and finish dates.

## Tree and table

The view has two representations:

- **Tree:** an expandable and collapsible hierarchy, with the **Expand all** and **Collapse all** buttons.
- **Flat table:** one row per item, ordered by level, with code, description, parent, level, order, progress and planned dates.

When the Time Schedule does not contain a parent item, the application rebuilds it as a **synthetic parent**: it is marked and its descriptive fields are empty.

## Who can do what

- Every site member can **consult** the structure.
- Only an **owner** can **import** a Time Schedule snapshot via API.
- An **owner** or **editor** can import an planning export with the **Time schedule** family from the Overview: see [Import a planning export](../../amministrazione/import-pianificazione/).

## What is not available yet

- Editing the items from the interface.
- Computing progress from WBS items: the percentage shown is the imported value; computed progress is in the [Site progress](../avanzamento/) view.
