The **Deviations** view shows the deviations of the selected site. They are data **imported from planning** and are read-only here: you do not create or edit them in the application.

## Consulting deviations

What it is for: knowing which deviations are open, who follows them and what has already been closed.

1. Open **Deviations** from the navigation.
2. Filter by **Status** and **Priority**. The menus include every value present in the data, plus “All statuses” and “All priorities”.
3. Choose the representation: **Board** for the columns by status, **List** for the table.
4. Open a card or a row for the detail.
5. In the detail read status, priority, description, author, assignee, PLC area, dates, amounts and linked references.

In the **board** each column shows the number of deviations; an empty column says “No deviations”. Deviations with an unrecognised status end up in a separate **Unmapped status** section.

In the **list** the columns are reference, title, status, priority, assignee, created and closed; headers sort the table.

:::caution[If a deviation is missing]
- Check the **Status** and **Priority** filters: an active filter narrows the list without warning.
- Deviations come from the planning import: a deviation missing from the file does not exist on the site. It cannot be created by hand from this view.
- If the status is not one of the expected ones, the card appears under **Unmapped status**: the export needs fixing.
- The view requires a connection: offline it shows a message instead of the data.
:::

## The detail

The detail shows:

- reference, status and priority;
- problem description, author and assignee;
- PLC area and creation, due, approval and closure dates;
- actual cost, claimed quantity, labour hours and completed task percentage;
- the **linked references**: progress item, task or diary entry.

The fields are read-only. To change a deviation, change the planning export and repeat the import.

:::caution[If the detail does not open]
- **Record no longer available:** the data changed after loading. Close the detail and reload the view.
- **Reference without a detail:** for tasks, diary and project structure the reference stays a label, not a link.
- **Offline:** the deviation detail requires a connection, even if the list was already visible.
:::

## Who can do what

| Action | Role |
| :-- | :-- |
| View list, board and detail | Every site member |
| Create or edit a deviation | No role in the interface: they come from the import |
