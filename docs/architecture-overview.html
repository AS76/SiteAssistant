Il flusso operativo da collegare

Export + file → anteprima → snapshot
→ Gantt / mappe → aggiornamenti interni → report

Fonte e lavoro interno distinti

Fonte: record e stati ufficiali conservati negli snapshot. Interno: note, piano corrente, consuntivi e verifiche. Nessuna modifica automatica al sistema sorgente.
